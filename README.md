# AICryptoCompliance

This repository contains a simple example of how to build a crypto compliance
agent that combines the OpenAI API with the Chainalysis Data Solutions SDK.

`sar_agent.py` defines a small LLM agent capable of fetching KYT (Know Your
Transaction) alerts and tracing addresses. The agent uses OpenAI function
calling to invoke Chainalysis queries, then iteratively builds a SAR narrative.

## Usage

1. Install dependencies:

```bash
pip install openai chainalysis
```

2. Export the required environment variables:

```bash
export OPENAI_API_KEY=your-openai-key
export CHAINALYSIS_API_KEY=your-chainalysis-key
export KYT_ALERT_ID=<alert-id>
```

3. Run the agent:

```bash
python sar_agent.py
```

The script will print the narrative generated by the model. Replace the example
SQL queries in `sar_agent.py` with the actual queries available to your
Chainalysis account.
